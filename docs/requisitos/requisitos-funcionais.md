# Requisitos Funcionais

| Código | Requisito Funcional |
|---|---|
| RF01 | O sistema deve permitir o cadastro de usuários. |
| RF02 | O sistema deve permitir a autenticação de usuários cadastrados. |
| RF03 | O sistema deve permitir o cadastro e gerenciamento de perfis financeiros pessoais e empresariais. |
| RF04 | O sistema deve permitir o cadastro de receitas. |
| RF05 | O sistema deve permitir o cadastro de despesas. |
| RF06 | O sistema deve permitir o gerenciamento de categorias financeiras. |
| RF07 | O sistema deve permitir o cadastro e controle de contas parceladas. |
| RF08 | O sistema deve permitir o registro do pagamento de parcelas. |
| RF09 | O sistema deve calcular automaticamente o saldo financeiro de cada perfil financeiro. |
| RF10 | O sistema deve permitir a consulta das movimentações financeiras utilizando filtros por categoria, período e tipo. |
| RF11 | O sistema deve permitir a geração de relatórios financeiros por período e perfil financeiro, com exportação em formato PDF. |
| RF12 | O sistema deve emitir alertas no próprio sistema para parcelas próximas do vencimento, com antecedência de 7 dias. |
| RF13 | O sistema deve permitir que administradores gerenciem os usuários cadastrados. |
| RF14 | O sistema deve validar CPF em perfis pessoais e CNPJ em perfis empresariais durante o cadastro e a edição do perfil financeiro. |
| RF15 | O sistema deve bloquear temporariamente o acesso do usuário após 5 tentativas consecutivas de autenticação inválidas. |
| RF16 | O sistema deve permitir a alteração de senha mediante confirmação da senha atual. |
| RF17 | O sistema deve permitir a atualização das informações financeiras do usuário, incluindo valores de renda. |
| RF18 | O sistema deve permitir a recuperação de senha por meio do e-mail cadastrado. |
| RF19 | O sistema deve permitir a edição e exclusão de receitas e despesas cadastradas. |
| RF20 | O sistema deve permitir o cancelamento de contas parceladas. |
| RF21 | O sistema deve atualizar automaticamente para "vencida" as parcelas pendentes cuja data de vencimento tenha expirado. |
